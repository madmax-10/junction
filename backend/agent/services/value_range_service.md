# Evidence-grounded AI valuation

`calculate_value_range(used_car_id, comparable_ids=None, user=..., provider=None)` authenticates ownership before evidence access. None or [] discovers eligible exact make/model posts without invented year/mileage tolerances. Explicit IDs restrict the evidence; malformed selections never broaden discovery.

The existing search service revalidates published Sell snapshots, approval timestamps, valid prices/year/mileage, synthetic flags, and excludes SellIssue owners at mock.local (seed_mock_data). Publication alone cannot prove listing authenticity; unidentified synthetic data remains a limitation.

With three eligible records, Gemini uses AGENT_MODEL and GOOGLE_API_KEY through google-genai and a Pydantic response schema to assign evidence relevance weights. The response must cover exactly the supplied IDs once, with finite weights in [0,1]. Prices are never accepted from the provider. Only public evidence attributes and basic subject vehicle attributes are sent; contacts and owner identity are omitted. The pure service computes a Decimal weighted mean. Provider failures or invalid responses return insufficient_data, never a successful fallback median. `provider` is injectable for offline tests.

Output retains legacy range/reference fields; median is deprecated and always null. estimated_value is an asking estimate, not calibrated real sales. No currency is invented. Missing or inconsistent currency metadata cannot establish a shared monetary unit and remains a data-quality limitation. No writes occur.

The subject sent for weighting includes its registered condition, make, model, year, mileage and trim. Tool data exposes `weight_evidence` containing each validated post_id, weight, provider reason and the server-owned asking_price. `method=ai_weighted_asking_mean` and `formula` identify the calculation. `weighting_provider` distinguishes Gemini from injected providers; `weighting_model` records AGENT_MODEL only for a validated default-provider response, otherwise null. Invalid/unavailable responses expose no weight evidence. Reasons are model explanations, not independently verified facts or instructions. No owner/contact identity is added to the audit output.
